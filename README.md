📌 Project Overview

The Business Automation System for Thirasara Max Mobile is a web-based e-commerce, repair tracking, and warranty management solution designed specifically for mobile accessories retail and repair operations.

🌟 Key Functional Modules

Module 1.0 - Authentication & User Management: Registration, Login, Profile Management & Role-Based Access Control (RBAC for Customer, Staff, Admin).

Module 2.0 - Product & Inventory Management: Catalog CRUD, Repairable product flag, Stock control & Automated Low Stock Alerts.

Module 3.0 - Order & Payment Management: Shopping cart, Online checkout via PayPal / Stripe, Order confirmation & transaction logs.

Module 4.0 - Repair Management: Online repair booking, Technician assignment, Live status tracking (Pending → In Progress → Ready for Collection → Completed).

Module 5.0 - Warranty Management: Automatic warranty creation for sales/repairs, digital validity verification, status monitoring & claim handling.

Module 6.0 - Invoice & Report Generation: Automated PDF generation for invoices, receipts, and monthly business reports (Sales, Repairs, Stock) via dompdf.

Module 7.0 - Notification Management: Automated email notifications for order confirmations, repair updates, and warranty expirations via PHPMailer.

💻 Tech Stack

Frontend: HTML5, Vanilla JavaScript (AJAX / Fetch API), CSS (Tailwind CSS)

Backend: PHP 8.0+ (Layered Modular / MVC Architecture)

Database: MySQL (via XAMPP / Apache PDO)

PDF Generation: dompdf/dompdf

Email Notifications: phpmailer/phpmailer

Payments: PayPal SDK / Stripe API
